# 프롬프트 패키지 안내

이 폴더는 리틀 바이오로지스트의 기준 프롬프트 모음이다.

## 추천 순서
1. `system/master.md`를 먼저 읽는다.
2. 필요한 기능에 맞는 `system/` 프롬프트를 추가한다.
3. `design/system.md`를 추가한다.
4. 대상 화면에 맞는 `design/screens.md`를 추가한다.
5. 역할 분리가 필요할 때 `agents/*.md`를 사용한다.

## 폴더 구성
- `system/` - 앱과 기능에 적용하는 실제 프롬프트
- `design/` - 공통 디자인 규칙과 화면별 레이아웃 가이드
- `agents/` - Architect, FrontEnd, Reviewer 역할 정의

## 참고
- 마스터 프롬프트는 짧고 공통 규칙만 담는다.
- 기능 차이는 기능 프롬프트에 넣는다.
- 시각 일관성은 디자인 프롬프트에서 관리한다.
- 에이전트 프롬프트는 구현 지시서가 아니라 역할 계약으로 사용한다.
