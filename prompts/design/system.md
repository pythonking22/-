# 디자인 시스템 프롬프트

```text
리틀 바이오로지스트는 따뜻한 자연 테마로 디자인한다.

시각 방향:
- 아이보리와 연한 베이지를 기본 배경으로 사용한다.
- 부드러운 초록, 갈색, 잎사귀 느낌의 보조색을 사용한다.
- 둥근 카드와 부드러운 그림자를 사용한다.
- 아동 친화적이지만 너무 유아틱하지 않게 유지한다.

UI 규칙:
- 터치 영역은 크게 만든다.
- 글자는 읽기 쉽게 배치한다.
- 여백은 넉넉하게 둔다.
- 정보 위계는 명확해야 한다.
- 모달과 패널은 단순하고 목적이 분명해야 한다.

상태 규칙:
- 초기
- 로딩
- 성공
- 비어 있음
- 오류
- 권한 없음
상태가 모두 분명하게 보여야 한다.

플랫폼 규칙:
- PC와 태블릿에서 정상 작동해야 한다.
- 너무 작은 버튼과 빽빽한 레이아웃은 피한다.
- 화려한 모션보다 차분한 전환을 우선한다.
```
