# 화면별 디자인 프롬프트

```text
특정 화면을 설계할 때 아래 규칙을 사용한다.

1. 목장
- 홈 허브로 취급한다.
- 서식지, 알/캐릭터, 나뭇잎, 진입 지점을 한눈에 보이게 한다.
- 탐험 욕구가 생기도록 공간감을 살린다.

2. 도감
- 분류 목록, 카드 그리드, 상세 패널 구조를 사용한다.
- 잠금 카드와 보유 카드를 분명히 구분한다.
- 등급 필터와 먹이사슬 또는 피라미드 컨트롤은 보조적으로 보이게 한다.

3. 탐험
- 업로드 동작이 가장 먼저 눈에 띄어야 한다.
- 분석 진행 상태는 명확한 모달 또는 상태 화면으로 보여준다.
- 성공과 실패 피드백은 헷갈리지 않게 구분한다.

4. 미션
- 진행도와 보상을 시각 중심으로 배치한다.
- 대표 캐릭터가 성장 상태를 함께 보여주도록 한다.

5. 친구
- ID 검색이 핵심이므로 검색 UI를 가장 먼저 보이게 한다.
- 친구 목록, 요청, 방명록 영역을 분리한다.

6. AI 말벗
- 캐릭터와 대화 흐름을 화면 중심에 둔다.
- 일러스트와 여백으로 성격이 느껴지게 만든다.

7. 상점과 가방
- 구매 가능 항목과 보유 아이템을 분리한다.
- 구매 후 가방 반영이 즉시 보이도록 만든다.

8. 퀴즈
- 집중도 높은 차분한 레이아웃을 사용한다.
- 문제, 선택지, 진행도, 정답 피드백을 각각 구분한다.
```
